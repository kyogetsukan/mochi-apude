# もちアプデ

**もちふぃった～の更新を、Unity のボタン一つで取り込む。**

もちふぃった～、更新のたびに BOOTH を開いて、zip を落として、プロジェクトごとに入れ直して……。
その往復を、Unity の中だけで完結させるツールです。

ボタンを押すと、あなたのアカウントで購入済みのもちふぃった～に新しい版が出ていないかを確認し、
出ていれば取得して、そのままプロジェクトに取り込みます。

---

## 動作環境

- Windows 10 / 11
- Unity 2022.3（VRChat SDK 3.x）
- VCC または ALCOM

> Mac では動きません。ギフトで受け取ったもちふぃった～も対象外です（商品ページに購入情報が出ないため）。

---

## 導入（最初の一回だけ）

### 1. リポジトリを追加する

下のボタンを押すと VCC が開き、リポジトリが追加されます。

**▶ [Add to VCC](https://kyogetsukan.github.io/mochi-apude/index.json)**

うまく開かないときは、VCC の `Settings → Packages → Add Repository` に次の URL を貼ってください。

```
https://kyogetsukan.github.io/mochi-apude/index.json
```

### 2. プロジェクトに追加する

VCC でプロジェクトの `Manage Project` を開き、一覧の **もちアプデ** の「＋」を押します。

### 3. BOOTH にログインする

Unity でプロジェクトを開き、メニューから
`Tools → 境月館 → もちアプデ → ウィンドウを開く`。
**「BOOTH にログイン」** を押し、開いた画面で普段どおりログインしてください。
ライブラリ（購入一覧）が出たら、その画面は閉じて構いません。**これは PC ごとに一回だけ**です。

## 使い方

ウィンドウのボタンは三つです。

- **更新をチェックして取り込む** … 新しい版があれば取得して、確認のうえ取り込みます。
- **入れ直す** … いま手元にある版を、もう一度このプロジェクトに取り込みます。
- **BOOTH にログイン** … 初回、またはログインが切れたときに。

取り込みの前に確認ダイアログが出ます。
下の **「次回からこのダイアログを表示しない」** にチェックを入れると、以後は自動で取り込みます
（元に戻したいときは同じダイアログの案内、または再チェック時に選べます）。

二つ目以降のプロジェクトでは、ダウンロードは走らず取り込みの確認だけが出ます（保存先は全プロジェクト共通のため）。

## よくある質問

**更新したのに「新しい版はありません」と出る**
制作者が同じファイル名のまま中身だけ差し替えた場合、変化を検知できないことがあります。
その場合は「入れ直す」で最新を取り込み直してください。

**初回起動で Windows の警告（SmartScreen）が出た**
署名のないツールのため出ます。「詳細情報」→「実行」で進めてください。

**新しい PC に移した**
「BOOTH にログイン」だけもう一度必要です。

**動かなくなった**
BOOTH のページ構造が変わると一時的に動かなくなることがあります。その場合はこのパッケージを更新します（VCC に更新が出ます）。
