# 【境月館】BOOTH Auto Updater｜購入済みユニパケの新版をBOOTHから自動導入【VPM対応】

BOOTHで買ったUnity向けツールや衣装が更新されたとき、
「BOOTHを開いて → zipを落として → プロジェクトごとに入れ直す」をやめるためのツールです。

Unityでプロジェクトを開くと、登録した商品に新しいファイルが上がっていないか確認し、
あれば自動で取ってきて、確認ダイアログのあと取り込みます。

■ 特徴
・制作者側の対応は不要。制作者は今まで通りBOOTHにファイルを上げるだけ
・購入・ギフト・無料配布のどれでも同じように使える
・購入していない商品は取れない（判定はBOOTHのログイン状態そのもの）
・ID・パスワードには触れない。ログインはBOOTHの画面で自分で行う
・VCC / ALCOM対応。プロジェクトごとの設定は「取り込むか」のチェックだけ
・ソース公開（MIT）

■ 動作環境
・Windows 10 / 11
・Unity 2022.3（VRChat SDK 3.x）
・VCC または ALCOM
※ Macでは、BOOTHからの自動取得は動きません

■ 導入
1. 商品説明のリンク「Add to VCC」を押してリポジトリを追加
2. VCCでプロジェクトに「BOOTH Auto Updater」を追加
3. Unityのメニュー Tools → 境月館 → BOOTH Auto Updater → BOOTH にログイン
4. 同メニューの「商品を登録・管理」に商品ページのURLを貼る

以上。以後はプロジェクトを開くだけです。

■ 注意
・BOOTHのページ構造に依存しています。BOOTH側の変更で動かなくなった場合はこのパッケージを更新します（VCCに更新が出ます）
・自分のアカウントで自分の購入物を取るだけのツールですが、pixiv様から問題があると示された場合は配布を停止します
・初回起動時にWindowsのSmartScreen警告が出ることがあります（未署名のため）
