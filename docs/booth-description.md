# 【境月館】もちアプデ｜もちふぃった～の更新をUnityから取り込む【VCC対応・無料】

もちふぃった～、更新のたびに
「BOOTHを開いて → zipを落として → プロジェクトごとに入れ直す」
をやめるためのツールです。

Unityのボタンを押すと、購入済みのもちふぃった～に新しい版が出ていないか確認し、
あれば取ってきて、確認ダイアログのあとそのまま取り込みます。

■ 特徴
・制作者（Nine Gates 様）側の対応は不要。今まで通りBOOTHにファイルを上げるだけ
・購入していないものは取れない（判定はBOOTHのログイン状態そのもの）
・ID・パスワードには触れない。ログインはBOOTHの画面で自分で行うだけ
・商品ページ→注文詳細だけを見る方式なので軽い
・「入れ直す」ボタンで、今の版をもう一度取り込み直せる
・ソース公開（MIT）

■ 動作環境
・Windows 10 / 11
・Unity 2022.3（VRChat SDK 3.x）
・VCC または ALCOM
※ Macでは動きません
※ ギフトで受け取ったもちふぃった～は対象外です（商品ページに購入情報が出ないため）

■ 導入（最初の一回だけ）
1. 商品説明のリンク「Add to VCC」を押してリポジトリを追加
2. VCCでプロジェクトに「もちアプデ」を追加
3. Unityのメニュー Tools → 境月館 → もちアプデ → ウィンドウを開く
4. 「BOOTH にログイン」を一度押してログイン

以後は「更新をチェックして取り込む」を押すだけです。

■ 注意
・BOOTHのページ構造に依存しています。BOOTH側の変更で動かなくなった場合はこのパッケージを更新します（VCCに更新が出ます）
・自分のアカウントで自分の購入物を取るだけのツールですが、pixiv様から問題があると示された場合は配布を停止します
・初回起動時にWindowsのSmartScreen警告が出ることがあります（未署名のため）
